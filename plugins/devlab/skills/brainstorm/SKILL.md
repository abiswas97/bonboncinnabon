# Brainstorm

1. Validate `.devlab/config.yaml`, map `search`, `fetch`, and `create` using `../../domain/notion-capabilities.md`, and read available repository guidance.
2. Explore one question at a time: problem, affected user, smallest useful version, alternatives, risks, and success criteria. Challenge vague claims without slowing down a clear direction.
3. If the idea contains three or more distinct deliverables, propose an Epic with named child Tasks. Epics have no story points and are not executable work.
4. Synthesize Description, Goals, Non-Goals, Acceptance Criteria, Open Questions, and planned children when applicable.
5. Show the complete page and properties. Obtain confirmation immediately before creating it in Notion.
6. Create the page in Backlog and report the connector result. Do not create proposed Epic children automatically.

Use `../task/templates/story-output.md` for page structure and `../task/reference/task-schema.md` for hierarchy rules.
