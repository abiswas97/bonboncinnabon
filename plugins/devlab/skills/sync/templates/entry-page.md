# Entry Page Structure

1. Hero callout: flat icon + one-liner description
2. Overview: 2-3 sentences (what, current version, what's next)
3. Roadmap table:
   | Pillar | Feature | Status |
   Status values: Done, In Progress, Planned, Next
4. Release and Distribution table:
   | Field | Value |
   Fields: Version, Platform, Distribution, Auto-Update, CI/CD, Framework
5. Divider
6. Product Spec sub-page link
